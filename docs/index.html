Synchronisation

Vos marques « lu » et « à lire plus tard » sont enregistrées dans un dépôt GitHub privé, ce qui les synchronise entre l'ordinateur et le téléphone. Saisissez les mêmes réglages sur chaque appareil.

Le jeton reste sur cet appareil et n'est envoyé qu'à api.github.com.
